# Contributing to Prism

Thanks for helping. Prism is built by a small team of maintainers working with AI coding agents, so clear tasks and small PRs matter.

## Find something to work on

- Open tasks live in [docs/ROADMAP.md](docs/ROADMAP.md). Pick a `todo` task whose dependencies are `done`, and comment on its issue (or open one) so nobody duplicates work.
- Issues labelled `good first issue` are a good start.

## Make a change

1. Fork and branch as `<task-id>-short-name`.
2. Read `CLAUDE.md` for conventions — it applies to humans too.
3. Run `pnpm install`, then `pnpm lint && pnpm test && pnpm build` before pushing.
4. Open a PR using the template. Link the task and requirement IDs.

## Sign-off

We use the [Developer Certificate of Origin](https://developercertificate.org/). Sign each commit with `git commit -s`.

## Code of conduct

Be kind and constructive. A full code of conduct will be added in task P0-15.
